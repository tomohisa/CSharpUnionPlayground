# UNION比較ベンチマーク

- [union100](union100/README.md): 100ケースのネストした大規模JSONを、C# 5方式・Rust・TypeScript・Java・Go・Swiftで往復します。最速の5バッチが合計約10秒になるよう件数を調整します。
- [projection100](projection100/README.md): 10ドメイン×10イベントからメモリプロジェクションを作ります。配列コピー・線形探索の劣化、状態数と履歴長の増加、ホスト実行とWASIを比較します。

どちらもコマンドラインで起動でき、処理時間、最大RSS、起動・準備・終了時間を保存します。`--quick`は動作確認用です。実測は各ディレクトリの`observed/`にあります。ハードウェア・ランタイム・具体的な実装に依存する結果で、言語全体の優劣を示すものではありません。

Intel実行とデータ更新は[GitHub Actionsの手順](actions/README.md)を参照してください。Mac ARMの計測とは別のスナップショットに保存します。
